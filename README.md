# PF: 0円運用向けポートフォリオ実践集

このリポジトリは「常時公開しない・デモ時だけ起動」を前提に、
副業提案に使える最小ポートフォリオ群と、案件獲得向け学習資料を収録しています。

## 収録ポートフォリオ
1. `portfolios/01_rag_local_demo`: FastAPI製RAGデモ（モック/実API切替）
2. `portfolios/02_image_inspection_demo`: Streamlit画像検査PoC
3. `portfolios/03_business_automation_demo`: Streamlit業務自動化（CSV集計 + 要約）
4. `portfolios/04_nextjs_saas_admin_mock`: Next.js管理画面模擬案件
5. `portfolios/05_fastapi_crm_mock`: FastAPI顧客対応自動化API模擬案件
6. `portfolios/06_django_booking_mock`: Django予約管理模擬案件
7. `portfolios/07_nestjs_linebot_mock`: NestJS LINE通知Bot模擬案件
8. `portfolios/08_laravel_ec_mock`: Laravel ECバックオフィス模擬案件
9. `portfolios/09_saas_monetization_ops_mock`: Demo版/有料版を切り替えるSaaS課金運用模擬案件
