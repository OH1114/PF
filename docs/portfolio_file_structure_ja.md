# ポートフォリオ全体ファイル構成ガイド（初心者向け）

## ルート構成
```txt
README.md                         # 全体説明
docs/                             # 学習・提案・運用ドキュメント
portfolios/                       # 模擬案件ごとの実装サンプル
tests/                            # 既存案件のテスト
```

## 主要ファイルの役割
- `README.md`: プロジェクトの入口。何があるか、どこから読むかを示す。
- `requirements.txt` / `package.json`: 依存関係を定義する。
- `.env.example`: 環境変数のテンプレ（秘密情報を含めない）。
- `.env`: ローカル実値（**Gitに含めない**）。
- `app/main.py` や `src/main.ts`: アプリ起動のエントリポイント。
- `core.py` / `service.py`: ビジネスロジック。
- `tests/`: 最低限の品質保証。

## `.env` 初学者向け手順
1. `.env.example` をコピーして `.env` を作る。
2. `replace-me` を自分の値に置き換える。
3. READMEの起動コマンドを実行する。
4. エラー時は「不足キー名」が出るので `.env` へ追記する。

## 注意
- APIキーをコードに直書きしない。
- `.env` や秘密鍵ファイルをコミットしない。
- 案件納品時は `.env.example` と設定手順をセットで渡す。
